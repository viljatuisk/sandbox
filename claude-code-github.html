Probleem: kuidas prototüüpe jagada?

☁️ OneDrive / lokaalne C-ketas

Fail salvestub isiklikku OneDrive'i. Jagamiseks tuleb link saata, aga kolleeg peab faili alla laadima — HTML ei avane OneDrive'is otse brauseris.

Nõuab allalaadimist final_v3_FINAL.html

💬 "Pane lihtsalt Directo OneDrive'i, sealt saab share'da?"

OneDrive share-link näitab küll alati viimast versiooni — aga kolleeg peab faili alla laadima ja avama oma arvutis. Kui ta laadis alla eelmise versiooni, on tal endiselt see vana fail.

✓ Minu valik — Claude Code + GitHub (Pages)

Teen muudatuse → push → link on automaatselt uuenenud. Kõik ajalugu säilib.

✓ GitHub Pages on päris veebiaadress — kolleeg avab brauseris nagu tavalise veebilehe, ei laadi midagi alla, ja näeb alati automaatselt sinu viimast versiooni.

✓ Püsiv URL ✓ Alati ajakohane ✓ Jagatav
04 / 07

Kuidas 'Claude Code + GitHub (Pages)' töötab — 3 sammu

1

💻 Claude Code desktopi rakenduses

Kirjutan Claude Code'le mida vaja: "tee KMD APA vaade tabeliga". Claude genereerib HTML-faili otse projektikausta. Minul on selle jaoks tehtud C kettale kaust Sandbox.

2

🔄 Git push → GitHub

Muudatused lähevad GitHubi hoidlasse. Kogu ajalugu säilib — saan alati vaadata mis millal muutus. Teen igaks juhuks ka käsitsi turvakoopiaid C ketta kausta.

3

🌐 GitHub Pages — jagamine

Kolleeg avab lingi brauseris. Ei pea faili saatma. Link on alati ajakohane.

Miks see valik on mõistlik?

📜

Versiooniajalugu

Iga muudatus on salvestatud. "Mis seal eile oli?" — git log näitab täpselt.

🔗

Püsiv URL

viljatuisk.github.io/KMD/ — link ei muutu, kolleeg avab alati uusima versiooni.

↩️

Tagasipööramine

Kui uus versioon ei meeldi, saan ühe käsuga vanale tagasi minna.

👥

Meeskonnatöö

Tulevikus saab kolleeg sama repo'sse panustada, kommenteerida, reviewda.
