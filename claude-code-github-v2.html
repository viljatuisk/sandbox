Probleem nr 1

Kus prototüüpe luua?

Chat (claude.ai)

Iga muudatus = uus vestlus, uus fail nullist. Chat ei mäleta eelmist faili.

  • Aeglane iteratsioon
  • Ei saa ühendada OneDrive'i ega lokaalse kettaga
Chat loob faili nullist iga kord — iteratsioon venib.
Claude Code (desktopi rakendus)

Kirjutan promti → Claude loob ja muudab faili otse minu arvuti prototüüpide kaustas (Sandbox). Sama vestlus, sama fail, järjepidev iteratsioon.

  • Kiire ja iteratiivne
  • Failid otse kaustas — ühendub lokaalse kettaga
  • Kõik ühes aknas: Chat + Cowork + Code (Desktop app)
Desktopi rakendus annab Claude'ile otse ligipääsu sinu arvuti kaustadele — Claude loeb, loob ja muudab faile ise, sina ainult kirjutad promti.

03 · 04
Probleem nr 2

Kuidas prototüüpe jagada?

Claude Chat

Genereerin faili → laen alla → saadan meiliga → kolleeg avab → teen muudatuse → saadan uuesti…

  • Aeganõudev
  • Nõuab allalaadimist — HTML ei avane OneDrive'is otse brauseris
  • final_v3_FINAL.html
Share-link näitab viimast versiooni, aga kolleeg peab faili ikkagi alla laadima. Vana allalaaditud fail jääb vanaks.
Minu valik — Claude Code + GitHub (Pages)

Teen muudatuse → push → link on automaatselt uuenenud. Kõik ajalugu säilib.

  • Püsiv URL
  • Alati ajakohane
  • Jagatav
GitHub Pages on päris veebiaadress — kolleeg avab brauseris nagu tavalise veebilehe ja näeb alati viimast versiooni.

Pane link brauseris järjehoidjate ribale (bookmarks) — edaspidi avaneb prototüüp ühe klõpsuga.
04 · 04
Töövoog

Kuidas 'Claude Code + GitHub (Pages)' töötab — 3 sammu

1

Claude Code desktopi rakenduses

Kirjutan Claude Code'le mida vaja: "tee KMD APA vaade tabeliga". Claude genereerib HTML-faili otse projektikausta. Minul on selle jaoks tehtud C kettale kaust Sandbox.

2

Git push → GitHub

Muudatused lähevad GitHubi hoidlasse. Kogu ajalugu säilib — saan alati vaadata mis millal muutus. Teen igaks juhuks ka käsitsi turvakoopiaid C ketta kausta.

3

GitHub Pages — jagamine

Kolleeg avab lingi brauseris. Ei pea faili saatma. Link on alati ajakohane.

muudatus  →  push  →  link uueneb automaatselt
