Probleem nr 1

Kus prototüüpe luua?

Minu valik: Claude Terminal (arvutisse paigaldatud tarkvara)

Kirjutan promti → Claude loob ja muudab faili otse minu arvuti prototüüpide kaustas (Sandbox). Sama vestlus, sama fail, muudatused sünnivad kiiresti.

  • Kiire muutmine ja täiendamine
  • Failid otse kaustas — ühendub lokaalse kettaga
  • Claude loeb, loob ja muudab faile ise — sina ainult kirjutad promti

Claude töötab iseseisvalt, samm-sammult kuni valmis

loeb failid→ kirjutab koodi→ kontrollib→ parandab vead→ ✓ valmis
Miks mitte Claude.ai brauseris? Brauser on "küsi ja saa vastus" — üks voor ja lõpp. Chat ei mäleta eelmist faili ega ühendu arvuti kaustadega: iga muudatus tähendab uut vestlust ja faili nullist loomist.
sina kirjutad→ Claude vastab→ lõpp

Probleem nr 2

Kuidas prototüüpe jagada?

Minu valik: Claude Code + GitHub (Pages)

Teen muudatuse → push → link on automaatselt uuenenud. Kõik ajalugu säilib.

  • Püsiv URL
  • Alati ajakohane
  • Jagatav
GitHub Pages loob mulle päris veebiaadressiga lingi — kolleeg avab brauseris nagu tavalise veebilehe ja näeb alati viimast versiooni.

Pane link brauseris järjehoidjate ribale (bookmarks) — edaspidi avaneb prototüüp ühe klõpsuga.
Miks mitte Chat või OneDrive? Genereerin faili → laen alla → saadan meiliga → kolleeg avab → teen muudatuse → saadan uuesti… Share-link näitab küll viimast versiooni, aga kolleeg peab faili ikkagi alla laadima — HTML ei avane OneDrive'is otse brauseris. Vana allalaaditud fail jääb vanaks.
aeganõudev nõuab allalaadimist final_v3_FINAL.html

Töövoog

Kuidas 'Claude Code + GitHub (Pages)' töötab — 3 sammu

1

Claude Code desktopi rakenduses

Kirjutan Claude Code'le mida vaja: "tee KMD APA vaade tabeliga". Claude genereerib HTML-faili otse projektikausta. Minul on selle jaoks tehtud C kettale kaust Sandbox.

2

Git push → GitHub

Muudatused lähevad GitHubi hoidlasse. Kogu ajalugu säilib — saan alati vaadata mis millal muutus. Teen igaks juhuks ka käsitsi turvakoopiaid C ketta kausta.

3

GitHub Pages — jagamine

Kolleeg avab lingi brauseris. Ei pea faili saatma. Link on alati ajakohane.

muudatus  →  push  →  link uueneb automaatselt
