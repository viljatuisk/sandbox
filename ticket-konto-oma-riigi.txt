TICKET: Pearaamat > Riigikonto filter (Konto korval "+"/lisa filter)
Faas: II

=========================================================================
TAUST / MIKS + KES
=========================================================================
Avaliku sektori asutused kasutavad riigi kontoplaani (koondplaani). Igal
oma kontol on konto kaardil vaste "Riigi konto" - uhe Riigi kontoga voib
olla seotud MITU oma kontot (nt riigi konto 551103 <- oma kontod 525812,
525832, 528101; voi 4010, 4011, 4012 <- 550010).

Soov: Pearaamatus saada voimalus filtreerida RIIGI KONTO (voi riigi kontode
VAHEMIKU) jargi. Nt riigi konto 550010 -> aruanne naitab koigi 4010/4011/
4012 tehingud.

Riigi konto on JUBA konto kaardi standardvali - pole pohjendatud seda
aruande filtreerimise parast lisavaljale dubleerida.


=========================================================================
KASUTUSLUGU
=========================================================================
Kasutaja maarab:
  Kontod: 0:Z
  + Riigi konto: 550010
-> aruanne naitab koik tehingud kontodelt, mille kaardi Riigi konto = 550010.

Oma kontod kuvatakse ERALDI RIDADENA (nagu tavaliselt) - see on FILTER,
mitte kontode koondamine uheks Riigi konto reaks.


=========================================================================
NOUE / LAHENDUS (universaalne "+" filter)
=========================================================================
Konto filtri korvale lisada "+"/mutrivotme (nupp), mille kaudu saab lisada
TAIENDAVA filtri KONTO KAARDI VALJADE jargi. Mehhanism on UNIVERSAALNE
(mitte ainult Riigi konto jaoks) ja laiendatav teistele konto kaardi
valjadele tulevikus.

1. Mutrivoti avab paneeli loeteluga konto kaardi valjadest, mida saab
   linnukesega filtriks lisada. Esimene (ainus praegu): "Riigikonto".
   Paneelis ka "Taasta algseaded".
2. Linnu markimisel tekib Konto valja alla "Riigikonto" filtrivali.
3. Riigikonto filter kasutab KONTO KAARDI standardvalja "Riigi konto"
   (MITTE lisavalja workaround'i).
4. Riigikonto filter toetab sama suntaksit nagu Konto vali - eelkoige
   VAHEMIKKU, nt:
       Riigi konto: 550000:559999
   samuti uksikvaartust ja loendit (550010,550020).
5. Riigi konto vaartused valitakse SAMAST Kontode registrist - eraldi
   riigikontode registrit EI ole.
6. Konto ja Riigikonto filtrid on VALIKULISED ja kombineeruvad (JA):
   - Tuhi Riigikonto filter ei piira midagi (tavaline aruanne).
   - Ainult Riigikonto taidetud (Konto 0:Z) = koik selle riigi konto(de)ga
     seotud oma kontod.


=========================================================================
KAITUMINE DETAILVAATES
=========================================================================
- Kuvatakse ainult oma kontod, mille Riigi konto vastab filtrile.
- Iga oma konto tavalisel kujul: grupipais + kanded + Kokku (periood) +
  Loppsaldo. (Kontosid EI koondata Riigi konto alla - jaavad eraldi.)


=========================================================================
KAITUMINE KOONDVAATES
=========================================================================
- Uks rida iga oma konto kohta (Algsaldo/Deebet/Kreedit/Muutus/Loppsaldo),
  piirdudes kontodega, mille Riigi konto vastab filtrile.
- Lopus "Kontod kokku".


=========================================================================
TESTID
=========================================================================
1. Vaikimisi (Riigikonto filtrit pole lisatud): aruanne toimib nagu tana.
2. "+"/mutrivoti -> paneel -> mark "Riigikonto" -> tekib Riigikonto vali.
3. Konto 0:Z + Riigi konto = 551103 -> kuvatakse KOIK selle riigi kontoga
   seotud oma kontod (nt 525812, 525832, 528101), igauks oma real.
4. VAHEMIK: Riigi konto = 550000:559999 -> koik kontod, mille Riigi konto
   jaab vahemikku (nt 551103 -> 525812/525832/528101).
5. Konto, mille Riigi konto EI vasta filtrile, ei kuvata.
6. Detailvaade: iga konto grupp + kanded + Kokku (periood) + Loppsaldo.
   Koondvaade: rida konto kohta + Kontod kokku.
7. Summade klappivus: Kontod kokku = kuvatud kontode summade summa.
8. "Taasta algseaded" / linnu eemaldamine -> Riigikonto vali kaob, filter
   tuhjeneb, taastub tavavaade.


=========================================================================
LAHTISED KUSIMUSED (kinnitada tootejuht / raamatupidaja)
=========================================================================
- Riigi konto VEERG aruandes: prototuubis "Vali tulbad" all linnukesega
  valitav (naitab iga konto riigi konto vastet). Kinnitada, kas jaab nii.
- Kas soovitakse ka VOIMALUST kuvada koondatult Riigi konto kaupa (uks rida
  riigi konto kohta)? (Praegune soov on FILTER + oma kontode read.)
- Millised veel konto kaardi valjad peaksid olema "+"/lisa filtri all
  valitavad (nt Kontoklass, Erisoodustus)? Praegu ainult Riigikonto.
